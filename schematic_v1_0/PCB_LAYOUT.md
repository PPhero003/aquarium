# PCB 布局说明

日期：2026-10-15。

当前 `Aquarium_ATO_V1_0.PcbDoc` 使用从立创 EDA 导入的真实商城封装重新建板并完成器件布局，尚未布线。

- 板框：110 mm × 70 mm。
- 用户坐标原点：板框左上角 `(0,0)`；Altium 内部绝对位置为 `(0,70 mm)`。
- 器件：64；焊盘：178；网络：41。
- 所有器件均在板内，器件外形相互重叠数为 0。
- 外围器件到板边的最小外形余量：左 1.86 mm、下 1.60 mm、右 2.10 mm、上 1.60 mm。

布局按整板信号流组织：电源输入、保险、保护和 AP63203 降压沿上边从左向右排列；水泵开关与输出靠右上；主控位于中部，去耦、复位和 SWD 就近；WiFi 接口靠右边；三个传感器接口沿下边等距排列；按键与 LED 位于右下并避开主走线通道。

后续布线应优先完成 AP63203 的输入环路、SW 节点、电感和输出电容，再完成泵的大电流回路；这些铜线应短而宽。主控去耦电容先直连电源脚和地，传感器与串口信号最后布线。顶层保留器件间通道，底层优先作为连续地平面。

`library_sources/EDA_LCSC_Footprint_Source.PcbDoc` 是未改动的立创封装母版。`PCB_PLACEMENT.csv` 记录最终坐标和封装名称，`eda-import-pcb-audit.txt` 是 Altium 回读结果。
